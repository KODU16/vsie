当前修改汇总
1. 控制椅、跨维度与 Sable 恢复
- 修正控制椅及武器、炮塔、推进器、护盾、屏幕、弹药箱、电池和燃料箱等外设的相对坐标 NBT 保存/恢复路径。
- 加入控制椅链接解析反馈循环，区分暂时缺失、恢复成功和确认删除，避免迁移过程提前清除绑定。
- 改进 Sable 子维度迁移、卸载和宿主维度切换后的控制椅注册重定位；VSIE 仅保留必要 NBT/注册恢复路径，自然 tick 延续由 Sable/DeepSpace 负责。
- 修正进入太空后的控制视角、鼠标锁定与 GUI 输入恢复。

2. 电磁导轨绑定与反馈
- 为电磁导轨核心加入稳定绑定 UUID 和客户端/服务端注册、重解析路径。
- 保持“控制椅—导轨核心”“导轨核心—弹射器”“弹射器—被弹射子维度”三段关系，并修复跨维度、子维度迁移和 NBT 重建后的恢复。
- 连接工具记录导轨核心时，以青色框和连线显示同维度可解析弹射器；跨维度或目标缺失时不绘制。

3. DeepSpace 与敌对设施
- 加入 DeepSpace HUD 桥接、数学计算、客户端渲染和独立开关；避免重复接管控制椅 tick。
- 加入敌对核心、敌对火炮和敌对机炮的方块、方块实体、菜单、网络设置、模型、纹理、战利品表及创造栏注册。

4. 世界区域 OBJ 导出
- 加入木棍外观的区域 OBJ 导出工具；两次右键记录角点，Shift+右键清除，选区保存在工具 CUSTOM_DATA NBT。
- 拒绝 Sable 舰船子维度选区；将可见方块表面导出为同名 OBJ、MTL 和纹理图集模型包。
- 支持模组方块烘焙模型、连接模型、资源包纹理和生物群系着色，并加入尺寸、面数和图集上限。

5. 自定义 GeckoLib 炮塔系统
- 加入自定义炮塔方块、方块实体、放置器、定义 JSON/NBT、GeckoLib 固定骨骼组与外部 OBJ 渲染。
- 编辑器改由 `/aeroie open_editor` 打开；放置器 Shift+右键选择定义，普通右键放置。
- 固定骨骼组为 root -> turret -> cannon -> long_cannon；玩家普通骨骼必须归属固定组，固定组和 firepoint 组仅允许编辑枢轴。
- 编辑器支持浮动/折叠窗口、文件夹模型包选择、保存目录选择、位置/枢轴三轴、枢轴居中、90 度旋转、左键平移、右键旋转和滚轮缩放。
- 加入炮塔类型、角速度、冷却、能量/非能量参数、firepoint 管理、HSV 激光颜色、多束激光检测和多开火点顺序射弹逻辑。
- 自定义炮塔继承公共炮塔基类，响应偏航/俯仰角度并进行客户端平滑；方块中心与 root 枢轴世界位置保持一致。

6. GUI 清晰度与本地化
- AeroIE 代码绘制 GUI 统一绕过世界模糊 shader，修正容器背景重复绘制和自定义炮塔编辑器遮挡顺序。
- 同步修正 EBL_core 数据终端模糊问题；补齐自定义炮塔、模型包选择和 OBJ 导出界面的中英文文本。

7. 控制椅模型与配色纹理
- 采用 control_seat.geo.zip 中的新控制椅 GeckoLib 模型；骨骼和 UV 契约不变，并为相邻表面加入极小 inflate 以减少闪烁。

- 自定义炮塔空骨骼模型的兜底纹理同步指向新目录；旧 textures/block/control_seat.png 已移除。

2026-08-13 自定义炮塔枢轴拖动带动骨骼位移修复
- 根因不是枢轴/位置命中分支重叠：一次拖动只锁定单个 activeAxis；实际问题是原实现只修改 pivot，而渲染矩阵使用 position -> pivot -> rotation/scale -> -pivot，已有旋转或非 1 缩放时改变枢轴必然带动网格斜移。
- 枢轴拖动现在按 position += rotation*scale*deltaPivot - deltaPivot 执行精确位置反补偿，使枢轴标识沿选定轴移动时，当前 OBJ 网格及其子级保持原世界位置；位置模式仍仅修改 position。
- 枢轴三轴改为按当前骨骼旋转与缩放后的真实局部轴投影，屏幕上的拖动方向、数值增量和补偿方向保持一致。
- 新增纯 Java 回归测试，覆盖带三轴旋转、非均匀缩放的蓝色 Z 枢轴拖动；修复前稳定复现网格斜移，修复后同一 OBJ 顶点变换前后坐标不变。

- 已放置的自定义炮塔、武器和推进器只在方块实体加载时检查一次外部 OBJ；若缺失则移除该部件，并向附近玩家发送红字聊天提示。
- 新增 /aeroie refresh_custom_devices [radius] 手动刷新指令，用于主动扫描命令源附近已加载区域并移除缺失 OBJ 的自定义部件。
- OBJ 客户端网格跳过零面积退化面片，避免用任意默认法线继续绘制异常面。

2026-08-18 自定义 OBJ 诊断反馈循环
- 区域 OBJ 导出新增 [AEROIE-OBJ-DIAG] 日志，记录选区体积、非空气方块、动态/未加载跳过、方向面剔除统计、烘焙面统计、通用面和退化面数量。
- 编辑器 OBJ 缓存重载新增 [AEROIE-OBJ-DIAG] 日志，记录设备类型、相对路径、实际路径和加载失败原因。
- OBJ 解析新增 [AEROIE-OBJ-DIAG] 汇总日志，记录顶点、UV、法线、三角面、四边形、n-gon、输出四边形、跳过退化面和发光材质数量。

2026-08-18 区域 OBJ 保守面剔除
- 区域 OBJ 导出不再直接使用 Minecraft 的 Block.shouldRenderFace 作为剔面依据，避免复杂模型、非完整方块和透明/特殊方块被邻接规则误删。
- 新剔面规则仅移除选区内部两个完整实心渲染方块之间的贴合面；其它邻接关系会保留并导出烘焙面。
- [AEROIE-OBJ-DIAG] 的 faceCull 字段现在表示保守规则下的完整实心方块内部贴合面剔除数量。

2026-08-18 区域 OBJ 贴图 UV 诊断与裁剪
- 区域 OBJ 导出会把烘焙四边形的局部 UV 限制在当前 sprite 的 0..1 范围内，避免 UV 越过纹理图集槽位后采样到相邻方块贴图。
- [AEROIE-OBJ-DIAG] 新增 uvClamped 与 spriteByDirection 字段，用于判断错误贴图来自 UV 穿槽还是模型烘焙阶段的方向贴图选择。
- 已通过 compileJava 与完整 check，未启动 Minecraft。

2026-08-18 区域 OBJ 贴图对应修正
- 区域 OBJ 导出不再完全信任 BakedQuad 携带的 sprite；若四个顶点的 atlas UV 中心不在该 sprite 范围内，会从方块 atlas 中反查实际 sprite 再写入导出纹理。
- 导出时会反向展开 Minecraft FaceBakery 的 UV shrink，避免独立 OBJ atlas 中继续使用原版防出血收缩后的贴图边界。
- [AEROIE-OBJ-DIAG] 新增 uvExpanded 与 spriteRemapped 字段，用于确认是否触发了 UV 展开或 sprite 重绑定。
- 已通过 compileJava 与完整 check，未启动 Minecraft。
